# Asset licensing

Only original, public-domain, CC0, or individually verified redistributable assets may be bundled. The asset manifest currently contains zero external binary assets. Registry-only costume entries deliberately have null model/texture references and are not claims that binary assets exist.

No Marvel, DC, film, game, fan-rip, marketplace, or unclear-license model, texture, sound, animation, PNG, WAV, or OGG is bundled.
